# papacrm

A lightweight CRM built with NukeJS, React, and MongoDB. Manage lists, documents, and custom workflows with a visual module editor.

## Features

- **Passwordless auth** — OTP-based login with JWT tokens
- **List & document management** — Create lists and save documents with custom fields
- **Visual workflows** — Build automation with a node-based module editor
- **Multi-language** — English and French support
- **Responsive UI** — Built with React 19 and Tailwind CSS v4

## Install

```bash
npm install
npm run dev
```

Start the dev server at `http://localhost:3000`. Production build:

```bash
npm run build
npm start
```

See [CLAUDE.md](./CLAUDE.md) for architecture and stack details.
